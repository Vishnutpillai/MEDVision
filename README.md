# MedVision AI

## Multimodal Chest X-Ray & Medical Report Intelligence Platform

MedVision AI is a machine-learning and AI-powered research/educational decision-support prototype that combines **chest X-ray image analysis** with **medical report understanding** and **retrieval-augmented generation (RAG)**.

The platform is designed to demonstrate an end-to-end AI workflow covering:

- Medical image classification
- Explainable AI with Grad-CAM
- Medical PDF/report processing
- Hybrid information retrieval
- LLM-powered grounded responses
- Case management
- Model evaluation
- AI-assisted review workflows
- Flask-based web application architecture

> **Important:** MedVision AI is a research/educational prototype and is not a medical diagnostic system. Its outputs should not be used as a substitute for evaluation by qualified healthcare professionals.
